# Pricing Cards UI

A simple, responsive pricing cards interface built with HTML and CSS.

## Features

- Three pricing plans: Basic, Pro, and Business
- Hover effects and smooth transitions
- Highlighted Most Popular plan
- Feature lists with check icons

## Technologies

- HTML5
- CSS3
- Tabler Icons

## Getting Started

Open `index.html` in your browser to view the project.
